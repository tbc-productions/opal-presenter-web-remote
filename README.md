# Opal Presenter Web Remote

This is the web remote that is integrated into Opal Presenter.

## Installation

To download and install this web remote, you need to install Opal Presenter 4.0 or higher, go into the configuration, select
"Remote" and update the web remote from there.

## Development

To get started with development of the web remote, see the [Developer Guide](docs/developer_guide.md) in the `docs` directory.
